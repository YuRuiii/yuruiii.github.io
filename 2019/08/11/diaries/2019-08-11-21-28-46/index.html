摸人屁股的十八岁男孩

2019-08-11

（我鼓了很大的勇气把韩梅梅同学的故事写出来。）

/

今天韩梅梅同学突然想起一件奇奇怪怪、她没咋跟人讲过的事情。

初中的食堂楼道熙熙攘攘，韩梅梅记得挺清楚。当时她初一，刚刚吃完午饭，穿着有点宽大的红白校服，在朋友前面蹦蹦跳跳地下楼。

学校错峰吃饭，高中的学生涌上来。上高中的学生仿佛不会笑，跟当时过于活泼的韩梅梅相比死气沉沉。很平常的时刻，人们拥挤地上下楼，空气嘈杂。

突然韩梅梅就被摸屁股了。

那是愣怔的一瞬间。一只手在黑暗的肢体之流中快速地抓住她的屁股，然后快速松开，快速汇入磅礴的肢体之流中，汇入半人高处无数运动的手臂、大腿屁股中。

当韩梅梅回过神回头向上看的时候，她只看到数不清的后脑勺，她没有看到那个摸她屁股的人。

/

韩梅梅的朋友对有人摸屁股的事情半信半疑，但是韩梅梅非常确定。尽管她没有亲眼看到，但是她知道那只手是在没人注意的角落快速寻找一个女孩子的屁股，一个藏在宽大校服里的女孩子的屁股，快速抓上去，快速松开，然后汇入肢体之流，不动声色地偷偷溜走。

韩梅梅的屁股有一种被人摸过的感觉，一直不消下去。

韩梅梅那个时候十三岁，还没有谈过男朋友，还没有跟男孩子真正意义上拉过小手。小学低年级她和男孩子手拉手排队队放学，高年级的时候有一次她故意把巴掌甩到男孩子脸上。但是从来没有男孩子摸过她的屁股。

韩梅梅的屁股有一种被人摸过的感觉，一直不消下去。

那种感觉不是痛也不是痒，只是一种被摸过的感觉。好像摸过很脏的东西不被允许洗手的感觉。你觉得无数细菌在拼命繁殖，因此皮肤麻麻酥酥，你觉得那些细菌下一秒就可以侵入皮肤，因此惴惴不安。

这是一种洗不掉的不洁的感觉。现在韩梅梅回想之前的事，那些事情异常清楚地浮现在眼前，韩梅梅的屁股仍然会浮现出那种被摸过的感觉。

/

同样的事情再次发生了。初一楼和高三楼联合的一段是厕所，韩梅梅和她的朋友一起去上厕所，她走在外面，她们聊着独属初一女生的那种类似小学生的天，一切都很寻常，一个穿白底黑条条校服的高中男生与她擦肩而过。

突然韩梅梅被摸屁股了。

厕所的那条走廊没什么人，她的屁股被快速抓住然后放下。韩梅梅赶快回头，那个男生以镇定的、从容不迫的步伐走回高三楼。韩梅梅愣住了，她没有叫住那个男生，他从容地走回他的班级，在转角消失身影。他过于淡定，她惊惶不已，仿佛她才是摸别人屁股的凶手。

楼道安静极了。

韩梅梅的软弱延展了许久。五年后她停在斑马线前面，被飞驰闯红灯逆行的电摩撞的倒下去。那个人质问她：“你不知道慢一点啊！”她很疼，不知道为什么说不出话。那个人挪开他的电摩，韩梅梅因此第二次摔下去，那个人飞驰而去。在他走之前，停满车的非机动车道也是同样的鸦雀无声。

韩梅梅的老毛病，在这种场合，她总是说不出话。

/

韩梅梅的屁股有一种被人摸过的感觉，一直不消下去。那是一种不洁的感觉，一种羞耻私密的感觉。

韩梅梅觉得对不起以后的男朋友，她的初恋也是她的丈夫，她那时是这样想的。因为她的屁股已经提前给人摸过了。

穿白底黑杠杠校服的男孩子成为韩梅梅和朋友谈话中低声恐惧的内容，被那个男生再一次摸屁股成为她最担心的事。韩梅梅开始绕远路上另外一头的厕所。

韩梅梅的屁股有一种被人摸过的感觉，一直不消下去。

/

那个高三的男孩子为什么要摸韩梅梅的屁股呢。

一开始她以为那是因为他喜欢她。有一次一个男生从后面扑上来搭她的肩，她慌忙挣脱。后来她知道那个男生只是想打招呼而已。无论如何，韩梅梅不喜欢摸屁股的打招呼方式，如果那个男生喜欢她，那这是来自变态的爱。

直到有一天，韩梅梅上体育课回来，在转弯处一拐头，看到那个男生在摸一个女生的屁股。这是韩梅梅第一次看到这个男生作案的过程。她的一个同班同学往前走，白底黑杠杠校服的男生和她擦肩而过，然后快速地把手伸向她的屁股。他没有回头看就熟练地完成了这个过程。另一个女生，也是她的同班同学，正在走来，他们即将擦肩而过。

韩梅梅吓得缩回头。

后来韩梅梅悄悄问第二个女生，她说她把他的手打掉了，所以他没有摸到她的屁股。韩梅梅觉得她真的很聪明，自己每次总是来不及打掉他的手。

/

韩梅梅坐在阿姨车上。阿姨回过头来问她：“你有被人摸过屁股吗？”她点头。阿姨的女儿也被摸了屁股。高一级的学姐说没有。

阿姨说：“我要给学校汇报这件事情。”

韩梅梅的妈妈说：“你们学校竟然还有这种变态！”

韩梅梅发现，她们班可能有不少女生都被那个男生摸了屁股。

但是静悄悄的，好像什么事情都没有发生。大家学习、做操、下课大吵大闹，没有什么人提摸屁股的事情。

五月走开，然后六月来临，韩梅梅的屁股逐渐消退了那种被摸过的感觉。韩梅梅心中狂喜，因为那个摸屁股的男生终于要走了。也是在一片安静中，那个摸人屁股的男生从此消失，仿佛从来没有出现过。

/

韩梅梅很晚才听说性骚扰的意思。

在此之前，她被摸过两次屁股，被抓过几次手，接受了几个男人奇奇怪怪令她不适的赞美。

韩梅梅很久以后才知道那个男生做的事情叫“性骚扰”，不仅仅让女生恶心，而且是完全完全完全不对的。

还有更多的事情，韩梅梅不知道该如何界定它们。韩梅梅的妈妈说“那是人家喜欢你！”，她觉得韩梅梅对男人们友好的亲近过于警惕而不识好歹，但是韩梅梅很小气，她总是觉得不舒服。

/

转眼韩梅梅也上高三了。

所以高三也不算很大，也不算很小。一个夜晚她突然回想起之前被摸屁股是事情，所有的细节都逐渐变得清晰起来，像在做一个不太美好的梦。

那个摸人屁股的十八岁男孩现在在哪呢？韩梅梅还记得他穿白底黑杠杠校服泰然自若走掉的背影。他当初为什么要摸女孩子屁股呢？他大概一共得摸了百十个屁股吧，但是大家都那么安静。他现在还有摸人屁股的爱好吗？他有没有过被人抓个现行呢？

这都是韩梅梅不知道的事情了。

如果回到初一厕所的走廊，她看着那个男孩向她迎面走来，瞄准她的屁股，正准备和她擦肩而过，韩梅梅会怎么办。韩梅梅如果清楚这件事情不是喜欢的表现，而是“性骚扰”，那她会怎么做呢？

我不知道，毕竟韩梅梅是一个软弱的人。

如果韩梅梅叫出来，她拉着他不让走，她告诉校长老师，那又会怎么样呢？会有怎么样的变化呢？

我也不知道，毕竟这个多变的世界，不曾有一个清晰的结局。

/

THE END.
