为什么呢

2019-05-11

（一）

为什么呢 我躺在床上 辗转反侧

如果摒除世间所有黑夜

我便只拥有全部光明

因此刚从楼下消失

怎么又在颅骨中出现了呢

/

那个夜晚 我越过许多山河去找你

带着满腔贞洁和无尽勇气

不过追逐阴谋

你是如何笑着

又慢慢化在月色里

一搅便不见 我不由得

心灰意冷

/

所以许多夜晚我去找你

试图在月光中寻找你的目光

我记得你的瞳仁如何化在满目苍白

我记得 我总记着

直到我忘了

/

所以昨夜梦中 我把该做的都做了

爱我的人都死了 人间稀薄

分驳着泥土的颜色

巨大的挺立于空

小黄点点的风

在我脸上溅出油漆质感

/

/

（二）

初夏初至 日子初始粘稠

脖颈后方 咸与淡的分界

由下至上

是我的海水和沙滩

/

爱极窗外夜的光泽与清凉气味

讲台上的男人说话

字字奶香

我喜欢他写数字3时

转折处圆润又乖顺

由于散光 一圈发光的边缘

/

这干净的世界 可爱

又不必要留恋

笔尖与纸笺或长或短 间间断断

有意义的接吻

这样的日子我不用狂喜或愤慨

不去街上劫持情绪 也不被劫持

/

快快地把人生回顾一遍

红色数字浓缩六十秒产生巨变

那一瞬间突然庆幸有陪我看月色的人。
