5/2 今天试图写诗

2019-05-02

[最近真的枯了…难以做到意象的不连续性和陌生化的表达]

（一）

我谈恋爱后再抒写爱情便不道德

只好讲述我没见过的

山川 河流 星辰

我的少年下楼时不敢看我

急匆匆奔往更深的一层

/

这破败的人间

我只见着公交车拖着长长的烟尘

试图上扬的语调 行驶至暮年

一个普通女人带雀斑的眼睑

头顶颤动的睫毛

我夜晚用直尺也画不出的线

/

我和这世界融合的是这么好

像脚穿上袜子 袜子穿上鞋子

大笑到下巴脱臼的时候

才会忘掉指尖跳动时

发现的错误的事情

/

寂寞的时候 望着木头也能心笙摇动

我的爱情只是一堵隔风的墙

但雨水渗进来 连同他的消息

他的同伴嬉笑地 寄来的

白纸

反正他不缺少

示爱

/

决定给我第一个小孩取名稻子

全然不顾 不认得 田野与秕谷

/

/

（二）

那些男人和女人

津津乐道他们的勾当

却对他们的生活

闭口不谈

静音的人群 张口闭口

像在比赛吐泡泡的鱼群

/

/

（三）

我关起自己 考了二百七十九名的夜晚

无数人冲我大叫

你他妈 你怎么不想想

你的爸爸呢

你的爸爸穿梭在城市的黑暗中

像一盏丑陋却明亮的大黄灯

/

我丢掉他 别人通知我的下午

瞥见窗外的天空

还没承载黄昏的意思

那个人是阴阳间来往的小鬼

年纪轻轻便仿着撒旦整了容

问我需要捎什么消息

我也没什么屁话好说

/

我试图叫喊 他把我往墙上撞的时候

自习教室的桌面是失血过多的

惨白天空

去你的故事 不过是文字的

排列组合

他撕碎我的的本子

反正不曾明晰的意思

我只是狂热地书写

迟早有一天我玷污的过的白纸

会亲自找我复仇

/

一定有人在背地里骂我

那么狠毒 飞鸟听到都惊落下来

先是仓促的悲鸣

然后是面粉袋子砸下的闷响

那些人骂呀骂呀

聚集起来

互相腐蚀耳朵和嘴皮

肢解我的金属器械轻轻碰撞

我的宿命 不约而同地到来

  • 随笔
